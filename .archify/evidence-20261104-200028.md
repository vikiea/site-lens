## 4. 事实清单（按图）

### D1 总览
- 启动：`lib/main.dart` 打开 `AppDatabase`、读 bootstrap、初始化健康调度、注入 Riverpod。
- 层：界面/控制器、发现与策略、媒体、本地数据；原生宿主；外部站点/发布/本地目录/DLNA。
- 限制：8 标签（`app_settings.dart:577`）、16 MiB 脚本、5 秒探测预算、8 并发初筛、后台播放默认 false。
- 数据边界：Cookie/WebView 存储/未确认脚本状态不进业务备份；媒体文件租约独立。

### D2/D5 宿主与导航租约
- `prepareNavigation`：撤销旧租约，ticket=generation；App 发起的导航最多跟随 5 跳；随后 `prepareFilterForNavigation` 或 `getScriptsForNavigation`；成功后 `install(url)` + `loadUrl`。
- `install`：写 `expectedUrl`/`leasedOrigin`/`accepting`；document-start 注入；特权世界前缀 `const __lensBridgeToken = ...;`；`@grant none` 进页面世界；`createPrivilegedWorld` 注册 `WebMessageListener("lensBridge")`。
- 历史导航：`prepareHistoryNavigation` 预授权、启动历史超时、不清 `expectedUrl`。
- 事件：`started/redirected/committed/loaded/scriptsSuspended/invalidated/hostInvalidated/certificateError/networkError/httpError/title/fullscreen/newWindow/interaction/mediaCandidate/mediaCandidatesClear/mediaPlaybackEvidence/filterStats`。
- 失败文案：`Navigation policy rejected`、`Navigation setup failed`。

### D3/D7 媒体
- 原生路径条件：`native != null && !candidate.isHls && !candidate.hasRequestHeaders`；否则 Dart。
- 状态：queued/downloading/paused/completed/playable/cancelled/failed/reauthorize。
- 工作切片 6 分钟；原生并发 1–6；`.part`+`.resume` → `.media` → `localRef`；授权失败 → `NativeMediaAuthRefreshService` 刷新后重试一次。
- 存储模式：app-private / SAF tree / direct path；权限 available/unconfigured/revoked/unsupported。
- 媒体库：登记、缩略图、repoint、移动/改名/删除、交付；导出 MP4 与缓存所有权独立；DLNA 投屏。

### D4 发现
- `maxConcurrentProbes=8`；`candidateDeadline=5s`；`ProbeTiming` 5s/3s；默认只验证前 3 个不同落点且串行；`all=true` 全部验证、最多 8 并发；单候选 HTTP+DOM 合计 5 秒；`landingKey` 去重排序。
- `ProbeStatus`：reachable/ready/unavailable/timeout/offline/certificateError/challenge/interactionRequired/unsupported/cancelled。
- 通知原文：`首页已就绪 N 个不同落点；仅初筛前三个不同落点。HTTP 可达不代表首页可用。`

### D6 脚本
- 16 MiB；元数据头必需；`@grant none` 不能与特权 grant 混用；`unsafeWindow` 不能与特权混用。
- 注册完整性：依赖数量/URL/SHA-256、资源 name/url/SHA-256、`currentDigest == approvedDigest`（legacy 例外）、`public` 模式需 `public_confirmed`；失败自动禁用并记录。
- `ScriptRegistration`：id、revision=currentDigest、privileged、rulesJson、source（替换 `__LENS_CONFIG__`）、sourcePath。
- 配置键：id、info.script、rules、grants、values（页面世界为空）、pageWorld、runAt、dependencies、resources、siteLens.networkMode。

### D8 媒体状态机
HEAD `lib/media/media_service.dart:1173` 的允许集合：
queued→{downloading,cancelled,failed}；downloading→{paused,completed,playable,cancelled,failed,reauthorize}；paused→{downloading,cancelled,failed,reauthorize}；completed→{failed,playable,cancelled}；playable→{cancelled,failed}；reauthorize→{downloading,cancelled,failed}；cancelled|failed→{downloading,cancelled}；非法迁移 `StateError`。

### D9 会话
- 标签 8；`unloaded/loading/ready/failed`；`ActiveBrowserSession.updateNavigation`。
- 前后台：非 resumed 时 flush watch saves、观察播放；策略串行化 epoch；非活动宿主在不可后台播放时失效并销毁，提示 `当前 WebView 无法暂停后台音频，网页已关闭；选择标签可重新加载`。

### D10 健康
- WorkManager 唯一任务 `site-lens-health-check`；charging+wifi；15 分钟 DB 租约；每站每天 2 次；HTTP-only；连续 2 次失败 → failing；仅在跃迁时发一次通知；健康不参与排序。
