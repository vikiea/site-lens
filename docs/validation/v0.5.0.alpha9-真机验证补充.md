# Site Lens `v0.5.0.alpha9` 真机验证补充

沿用 alpha6、alpha7、alpha8 真机流程。alpha9 增加共享缓存并发验收：

- 两个媒体任务同时请求同一 HLS 分片时，磁盘只出现一个共享资源 writer 和一份已提交资源。
- 一个任务取消或删除时，另一个任务仍可继续读取共享资源。
- 播放或下载 writer 活跃时尝试清理，操作必须被拒绝并显示“资源仍在写入”。
- 模拟进程异常后重新打开任务，过期写入租约可以恢复，已有 `.part` 断点继续使用。

包身份：`0.5.0-alpha9+107`，标签约定为 `v0.5.0.alpha9`。
