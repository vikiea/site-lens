## 真实站点证据

以用户指定发布页为入口，经用户年龄确认后进入镜像站点。测试只记录技术状态，不保存标题、截图或临时签名到仓库。

| 环境/步骤 | 实际结果 | 边界 |
| --- | --- | --- |
| 桌面 Chrome：发布页、镜像、播放详情 | 发布页 HTTP 200；实际 blob/MSE 视频 readyState=4，播放时间推进 | 不等于 Android WebView 通过 |
| macOS Dart 默认直连策略 | DNS 返回 198.18/15，按策略拒绝 | 本机路由指向 utun；不是代理下载通过证据 |
| macOS Dart TUN 网络探针，首次 | HLS 清单 200；密钥 CDN TLS 握手被断开，有限重试后任务失败 | 本轮未复现清单 HTTP 403；不能认定证书或代码根因 |
| 同一清单后续 CDN 节点轮换，Dart 实际下载服务 | 清单 200 / 7065 字节；密钥 206 / 16 字节；分片 Range 206 / 65536 字节；完整下载 39 分片、1 密钥、83176007 字节，任务 playable | 完整缓存下载成功；未执行 Android 原生播放、转封装和 SAF 交付 |

新代码补了完整资源身份与 partial 身份隔离、签名轮换时 validator 核验、TLS/HTTP 断流有限重试、PAC 候选回退。CDN 节点切换及网络路径仍可能间歇失败，不能从一次成功推导全部源站已修复。

已知兼容边界：依赖下载响应新 Set-Cookie 的站点，以及要求跨域 iframe 发起文档 Referer/Origin 的站点，仍需对应夹具和设备证据；本次尚未证明样例站点触发这两项。
