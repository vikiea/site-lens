## 新增验收点

- HLS 播放中 seek 到尚未缓存的后续时间点。
- 记录代理或服务端请求顺序，目标分片应先于普通顺序 backlog 请求。
- 本地清单仍按 HLS 原始顺序发布，播放器时间线不能被请求重排改变。
- 多任务同时下载时，播放任务优先但普通任务最终仍获得执行机会。
- Activity/Flutter bridge 重绑后继续使用同一原生 MediaSession，不创建第二个播放器。
- 后台授权刷新区分 `waiting_execution` 和 `reauthorize`，且刷新失败保留断点。
- 删除观看 owner、下载 owner、MP4 artifact 和源 HLS 时分别验证所有权，不用单一删除按钮推导级联行为。
