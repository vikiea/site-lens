# 启动、浏览浮条与设置页人工验收

本批基线为 v0.4.0.alpha13；本文件给出后续测试包的操作用例，不表示已完成真机验收。
按用户要求采用本地静态检查、确定性回归、正式测试包与人工验证。旧版本已通过的
代理、媒体和生命周期证据仍保留，以下回归仅覆盖本批影响及必要的交叉边界。

## 测试准备

- 通过 GitHub Release 安装本批测试 APK，保留既有数据，记录版本号、设备型号、
  Android/API、WebView provider、玻璃实际策略。不要卸载清库来准备冷启动。
- 准备一个保存标签、四个内置源已启用且已下载规则；另准备多标签与已有媒体任务。
- 无敏感数据的受控站点提供广告测试资源、用户脚本标记、HLS/fMP4/AAC 视频和
  SPA 换集。保存剧集标题、清单、片段首帧/内容的对应关系，不能仅比较候选数量。
- 每一项记录通过/失败/未执行及截图或操作记录；失败附错误日志。不要保存账号、
  Token、Cookie、签名 URL、调试端点或应用数据库到公共报告。

## 本批必测

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| S01 | 保留一个标签和四源规则，系统强行停止后重新打开 | 首页和标签快捷入口先可用；无需等待媒体恢复或过滤规则编译，首页不持续转圈等待这些工作 |
| S02 | 冷启动后立即打开保存标签，再快速返回首页 | 只打开所选标签；规则与脚本准备后导航，返回后不被迟到任务重新拉回网页 |
| S03 | 冷启动立即开始站点侦察/检测 | 等必要的规则/脚本/设置就绪；不绕过过滤或脚本权限；退出可取消 |
| S04 | 冷启动立即进入媒体任务/媒体库，启动下载或删除 | 恢复中可显示局部等待；任务、导出索引与文件不会被迟到恢复覆盖或删除 |
| S05 | 切后台、杀进程、再次进入；关闭标签及关闭恢复标签开关后重启 | 无重复/复活标签；选择和恢复开关持久化；媒体任务仍可恢复 |
| D01 | 首页、浏览标签管理、媒体、设置及其二三级页各查看浮条 | 有标签时显示一个吸边竖条，首页/档案详情不再有重复返回条；浏览一级菜单保留 |
| D02 | 拖动竖条上下及左右边，跨页并重启 | 吸附左/右边，位置保留；不会遮挡底部导航、安全区域，拖动不意外打开网页 |
| D03 | 点竖条，再点展开后的标题；快速连点标题 | 第一次只展开，第二次进入当前标签；仅推入一个浏览页，长标题省略但可访问性语义完整 |
| D04 | 多标签时关闭浮条当前标签，再关闭最后一个 | 每次仅关当前标签；选择邻居但不在 Flutter 页偷偷加载它；零标签浮条消失 |
| D05 | 网页加载中/失败页、原生播放器、全屏、弹窗、菜单、键盘及页面转场 | 浮条隐藏；退出恢复普通 Flutter 页面后再显示，不与网页自有控件重叠 |
| U01 | 软件更新页，依次稳定版/测试版 | 更新渠道与选项一行，无渠道描述；当前版本只展示版本号且在检查更新面板内 |
| U02 | 检查更新、切渠道、下载暂停/继续、返回后重进 | 既有更新/缓存/下载功能正常；检查不会因布局改动额外自动请求网络 |
| C01 | 设置→设备能力与平台策略→编解码器清单 | 进入自动读取，无需点击读取按钮；只读取系统描述，不启动编解码器或媒体播放 |
| C02 | 退出清单，五分钟内反复进入 | 直接显示已有缓存；不重新枚举；缓存读取不延长首次成功读取的有效期 |
| C03 | 首次成功读取满五分钟后再次进入 | 自动重新读取一次；失败显示重试，失败结果不作为新的成功缓存 |
| C04 | 长清单滚到底，展开最后项再收起 | 一处滚动视口、可达清单末尾，不重复读取；高质量模式无黑块/叠印/滚动卡死 |
| A01 | 外观→不透明度，拖动并点击55默认标记 | 标签、数字和滑动条保持同一行；0/55/100正确生效，重启值保留 |
| A02 | 320/360宽、系统字体放大、深/浅色、一个非默认主题 | 更新渠道、不透明度、展开浮条无溢出、误触；主要操作可触达 |

C02 的“未重新枚举”可结合开发日志/原生方法计数验证；单凭列表内容相同不足以证明。
C03 采用重新进入触发过期读取；页面保持打开时不定时轮询系统清单。

## 媒体、代理、Media3 与 HCPP 交叉回归

| 编号 | 操作 | 预期及证据 |
| --- | --- | --- |
| X01 | 设置系统代理后站点侦察、检测、打开受控站点；恢复原代理后重做 | 路由按系统策略，无代理阻止误报；失败区分代理、DNS、TLS；记录各阶段结果 |
| X02 | 当前网页切上下集，不刷新；同URL SPA fetch/XHR、返回历史页 | 当前集清单重新上报；旧请求/BFCache迟到响应不能覆盖新集；逐集核对媒体内容 |
| X03 | 批量选择全部剧集，分别播放头尾片段 | 标题、剧集、清单、实际内容逐一对应，不能仅数量一致 |
| X04 | 代理下下载HLS、AES-128、EXT-X-MAP、fMP4，多分片音频 | 进度刷新，片段/密钥/init完整；下载可暂停取消，导出无需网络 |
| X05 | Media3播放/seek/转MP4；H.264/H.265 B帧、AAC | decode order/PTS/音画同步/EOS正确，非隐式转码；缓存删后独立导出可播放 |
| X06 | 导出后删下载任务，另测删缓存和媒体库删导出 | 删除任务/缓存不连带删导出；不同所有权文件行为与确认文案一致 |
| X07 | 原生后台播放、通知暂停/继续/上下集；网页媒体控制 | 当前媒体身份正确、切集无重叠音频，退出及取消释放lease |
| X08 | API34+ Vulkan/HCPP、API34以下、API34+非Vulkan分别打开WebView | 设置显示真实能力和有效平台策略；原生WebView控件保留surface role，Flutter玻璃符合策略 |
| X09 | 高质量全部面板、长codec列表、0/55/100、WebView叠层 | 观察连续滚动与转场像素；HCPP supported声明不能代替渲染验收 |
| X10 | SAF导出/重新授权、DLNA接收端、进程回收、旧Token升级读取 | 分别在实际provider/接收端/旧安装执行；缺设备证据保留未验 |

未执行的矩阵仍为待验：旧API/非Vulkan、iOS、旧Token、真实DLNA接收端、不同SAF
provider、所有网络/CDN及完整视觉组合。本批发布不宣称这些边界已通过。

## 后续自动化入口

需要真机自动化时按 `site-lens-validation`、`docs/development-setup.md` 和 Make 目标执行；
`make acceptance DEVICE=<当前serial>` 使用来源绑定备份与恢复。不要直接安装验收包覆盖
正常数据，不重复连接旧端点。`integration_test/modernization_test.dart` 已适配清单自动读取。
完整 L3/L4 所需设备证据、APK正式签名检查和 GitHub workflow 各自记录，不能相互替代。
