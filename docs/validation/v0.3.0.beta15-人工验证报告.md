# v0.3.0.beta15 人工验证报告

日期：2026-10-21（Asia/Shanghai）。基线为 `v0.3.0.beta14`。本轮按用户最新要求快速修复已确认问题、提交并发布测试包；取消模拟器和真机验收执行，保留现有设备用例并补充缓存清理回归。以下“待人工验证”均不代表通过。

## 本轮改动

- DLNA 临时任务的所有权覆盖远程 HLS 失败、下载、转换和本地 MP4 投屏全过程。启动页释放自己的引用后，活跃投屏仍保有文件；会话结束后才允许删除。
- 临时任务清理走统一下载删除流程，即使尚未生成 MP4，也删除 HLS 缓存和未完成文件。清理异常记录到 `media.cleanup`，保留重试标记，避免覆盖原始投屏结果。
- 投屏前等待任务持久化并使用数据库的 canonical row；遇到历史 `cache_key` 冲突时，不把已有任务当成新建临时任务删除。
- Dart 下载遇到 `SocketException` 连接重置，在原有有限次数重试后使用已有 Android 原生续传通道；沿用原生代理、证书、路径和断点校验，不忽略 TLS 证书错误。

候选去重、SQLite 冲突、选集边界提示、可读路径等沿用 beta14 基线。本轮没有扩大媒体身份合并范围。
