# v0.4.0.alpha16 P2 观看保存前置验证

日期：2026-10-24。代码基线为当前 `codex/browser-startup-dock` 工作区。

## 已实现的局部范围

- `PlaybackEvidence` 继续只接受候选相同 frame/document 的稳定确认。
- 新增 schema 13 的 `watch_saves` 表和独立 `WatchSave` 模型。
- `WatchSaveStore` 只在稳定播放证据同时具备剧目和集数身份时写入 owner。
- 默认关闭 `autoSaveWebPlayback`；设置记录可以持久化和迁移。
- 当前 tab、host、evidence 对象在写入前仍需保持一致；迟到事件被丢弃。
- 观看 owner 不创建 `MediaTask`、不启动下载、不取得文件租约。

## 本地证据

- `flutter test test/watch_save_store_test.dart test/settings_repository_test.dart test/profile_migration_test.dart test/native_hosts_media_test.dart`
- `dart analyze`

上述定向测试和静态分析在本地通过后，仍需运行当前工作区的完整 `make check`。

## 未完成和设备边界

- 观看保存列表、进度、批量管理、清晰度/音轨表示形式管理尚未接入 UI。
- P1 共享缓存/资源 owner、P3 Media3 部分缓存播放、P4 后台调度和 P5 受限授权刷新仍未完成。

- 这组本地证据不代表 Android 后台播放、边下边播、真实代理下载或设备生命周期已通过。
