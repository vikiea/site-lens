# v0.4.0.alpha17 验收检查点

日期：2026-10-24（Asia/Shanghai）。代码基线为 `v0.4.0.alpha16` / `8f4676f`，当前发布版本为 `0.4.0-alpha17+95`，对应标签 `v0.4.0.alpha17`。本文件记录 alpha17 修复、自动检查和真机验收证据，并保留后续人工复核入口。

## 本批改动

- SAF 媒体授权失效统一映射为 `media_permission`，媒体库元数据读取不会再把权限失效误判为编解码器问题；界面显示“媒体目录访问权限已失效，请重新选择保存目录”。
- Media3 检查 SAF 文档前先复制到应用私有临时文件，限制单文件 256 MiB，支持取消和陈旧临时文件清理；扫描遇到未知大小时不再写入负数。超限、空文件和超时返回专用错误，不再静默降级。
- Android 36 Qualcomm/QTI 设备启用 Flutter Impeller Vulkan teardown 兼容保护，改走 Skia/OpenGL；设备诊断记录实际策略，高质量 codec 验收允许受保护设备使用兼容填充路径，并确认不挂载 `AdaptiveGlass`。
- 后台读取 WebView Cookie 改为主线程桥接，避免 `FlutterJNI.dispatchPlatformMessage` 在线程池线程执行造成 `@UiThread` 异常。
- 发布版本和发布文档同步为 `0.4.0-alpha17+95`；版本校验要求与 `v0.4.0.alpha17` 标签一致。
