## 改动与本地检查

- 全局浏览浮条收起宽度为原来的三分之一，左右贴边、外直内圆并保留六点与
  48dp 手势目标；网页内自由拖动把手的交互保持独立。
- 媒体管理、软件更新各合并为一个面板；透明度使用 `n / 100` 并右对齐滑杆。
  MP4 保存目录与恢复媒体库说明可展开完整详情，折叠行高保持不变。
- 新批量下载使用剧名目录；旧批次只清理确定的自动后缀。已有缓存及重试目录
  身份保持原值，普通/用户重命名/移动/含子目录的根保持用户管理。
- WebView 后台请求事件和过滤统计转到主线程，并拒绝旧文档/已退出宿主事件；
  DLNA 通过 Android Socket.localAddress 选择本机监听地址，保留错误 cause。
- 独立代码复审 APPROVE；修复复审中发现的目录范围、滑杆对齐、路由错误链、
  子目录归属和完整超时包装问题。UI SKILL 与设计 Token 同步更新。
- `make check`：642 项 Flutter、静态分析、Pigeon 生成和全部 JS/Python 契约通过。
  定向 Flutter 为 172 项；Android `:app:testDebugUnitTest` 为 19 套件/113 项，
  0 failures / 0 errors。
- L3 同批构建 debug/正式 APK，包名与固定正式证书核验通过。正式测试版的
  versionName/versionCode 和资产上传由发布工作流负责，不以本地编号代替。

## 验证矩阵的边界

| 范围 | 本批证据 | 保留边界 |
| --- | --- | --- |
| 系统代理与 HTTPS HLS | 本批未重跑显式代理专项，复用未受影响的 alpha13 五阶段应用流量与资源摘要证据 | 本批完整 L3 的代理夹具未启用；既有 HTTPS HLS 夹具无 AES key |
| 媒体身份与剧集匹配 | 同页 fetch/XHR、显式 SPA 映射和迟到响应自动化通过 | 不证明源站剧情语义或物理 BFCache |
| Media3 | 五组完整本地资源 parity/seek 通过 | 部分资源边下边播尚未接入 |
| HCPP 与诊断 | 当前设备能力、118 项 codec 滚动；历史 18 帧像素矩阵按影响复用 | 连续滚动/转场像素、其他 API/GPU 与非 Vulkan 仍待验 |
| 模拟器 | 真机在线，按用户要求使用真机 | 历史模拟器因主机 swap 停止，不计为本批设备验收 |
| DLNA / SAF | 本机路由和文件许可通过 | 真实非同址电视与不同 SAF provider 仍需实物证据 |

原生服务持有播放器和队列 B0–B3、观看保存/共享索引/边下边播 P0–P8、iOS、
旧 Token 迁移和长期内存仍为独立未完成项。发布本批不替代这些子计划的实现或验收。
