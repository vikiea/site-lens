# v0.4.0.alpha16 验收检查点

日期：2026-10-24。代码基线为 `v0.4.0.alpha15` / `15f7763`，本批为其后的本地修复集合。
本文件只记录当前工作区能够证明的事实；设备验收、GitHub Verify 和 Release 仍分别取各自的实时证据。

## 本批改动

- 媒体目录迁移在 Android 原生侧使用目录锁、活跃任务保护、迁移 journal 和文件摘要校验；Dart
  侧同步重写媒体任务与导出物引用，旧批次目录按确定后缀合并同名文件并覆盖目标副本。
- 删除媒体任务前冻结 Dart 缓存集合并取得原生 mutation reservation；导出副本清理复用任务 reservation，
  Engine detach 会取消本运行时持有的 reservation 和下载写入。
- 首次高质量面板切换通过稳定内容 sibling 保留输入、焦点和滚动状态，避免首帧全局白屏/重挂载。
- GitHub Token 输入改为有状态对话框，校验失败留在对话框内；更新页继续保留 API 授权错误的可读提示。
- 发布工作流要求同一提交的 `pubspec.yaml` 版本名、versionCode、标签和 APK manifest 一致；当前版本为
  `0.4.0-alpha16+94`，对应标签 `v0.4.0.alpha16`。
