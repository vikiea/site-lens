## 发布前恢复缺陷复审

独立审查发现 shared MP4 脱离复制在“已发布缓存副本、引用保存失败”后重启会被
已有目标阻断。修复只对该恢复路径显式允许复用；原生在完整目标变更许可和源读
租约内校验非空、长度与 SHA-256，相同副本直接接管而不重写。同名默认仍拒绝，
不一致、取消和读取失败不会删除旧源或错误接管。
媒体库 33 项包含失败后立即重建 Store/Library、同长异内容拒绝和成功重试；新增
6 项纯 JVM 正反例随原生 105 项通过，限定复审 APPROVE。该修复不宣称已经完成
所有 Engine detach 持久回执或未发布 `.part` 文件的恢复子计划。
随后对当前真机执行受保护的原生文件租约单用例：默认同名拒绝、相同副本复用且
修改时间不变、同长异内容拒绝、源和目标保持可读均通过；正常包与来源绑定数据库
SHA-256 恢复通过。未重跑未受该修改影响的 Media3 全量样本或 HCPP 截图矩阵。

迁移、iOS、物理 BFCache 和长时间内存/连续滚动证据不计为本次已完成。
