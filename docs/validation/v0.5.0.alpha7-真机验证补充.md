# Site Lens `v0.5.0.alpha7` 真机验证补充

完整流程沿用 [alpha6 真机验证流程](v0.5.0.alpha6-真机验证流程.md)。alpha7 只增加两项必须在真实设备复核的回归：

1. 播放本地 MP4 或完整 HLS，暂停后销毁 Activity/Flutter Engine，再重新进入媒体页；确认恢复的是同一 session，状态仍为暂停，位置和倍速不回退。恢复后关闭播放，确认文件可以删除或移动。
2. 选择 HLS VOD，下载第一个分片后立即开始播放；确认首帧早于全量下载完成，下载继续增长。拖动或快进到尚未缓存的时间点，确认应用等待增量清单覆盖目标后执行 seek；超时要显示原因并保留任务。暂停用户播放时，系统缓冲回调不能自动恢复播放。

记录：设备型号、Android 版本、WebView/Media3 日志、锁屏通知截图、`dumpsys media_session` 输出、播放 session ID、缓存目录和 lease 释放结果。

alpha7 测试包身份：`0.5.0-alpha7+105`，标签约定为 `v0.5.0.alpha7`。
