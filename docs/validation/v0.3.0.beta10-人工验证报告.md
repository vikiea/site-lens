验证日期：2026-10-20 至 2026-10-21（Asia/Shanghai）。基线 `v0.3.0.beta9 / 5de1ce1`。分支 `feature/browser-enhancement-release-channels`。本轮为分阶段测试版，按用户已允许先发布并随后修复测试问题的安排推进；完整 L3/L4 未通过，未验证或失败的场景保留原状态。
