# Android 现代化执行与交付说明

执行范围为 Android 首版、小规模分享。iOS 保留源码和 Pigeon 接口，媒体方法返回不支持；本轮不声明 iOS 验收。

## 产品行为

- 一级导航固定为「站点 / 浏览 / 设置」。脚本管理位于设置二级页面，浏览菜单提供当前档案与未绑定脚本入口。
- 全局 iOS 27 液态玻璃：顶部栏、底部导航、内容面板、标签卡片、菜单、弹窗、提示条共用一套材质、圆角、间距与状态色；背景是随主题色变化的静态柔和渐变。使用 `liquid_glass_widgets 1.13.0` 的 `ios27Light` / `ios27Dark` 预设与独立 `SiteLensGlassQualityStrategy`。默认和标准模式下内容面板保持 `standard`，WebView 上方控件始终保持实时 backdrop；`自动` 模式允许静态 chrome 按帧耗时争取 `premium`，手动`高质量`模式锁定导航 chrome 为 `premium`。开启“高质量覆盖全部面板”后，Flutter 内容面板、弹窗、sheet 和玻璃卡片也使用 `premium`，但不改变 WebView 覆盖层约束。默认不透明度为 `55`，浅色使用中性浅灰 `#E7EAEE`、深色使用中性炭灰 `#25272B`，与静态背景保持足够对比；普通 Android 页面正常使用 premium 光学参数，只有 WebView 路由可见期间临时使用 0.1.3 的安全参数，避免与原生 WebView 合成路径触发厂商 GPU 问题；shader 或 renderer 不可用时，非 WebView 覆盖的 Flutter 玻璃表面走兼容性的裁剪半透明 Material fallback，WebView 覆盖层继续使用实时 backdrop。`GlassAccessibilityScope(reduceTransparency: false)` 保证高对比度不换材质，Reduce Motion 只停动效。普通按钮、FAB、浮动把手与导航项没有额外阴影。
- 明暗模式是外观区的行内分段选择，主题色是默认折叠的内嵌色板；提供星海蓝、雾松绿、鸢尾紫、玫瑰灰、砂岩铜、石墨蓝灰。主题 ID 用 snake_case 保存。玻璃质量提供「自动 / 标准 / 高质量」三档；「自动」按设备帧耗时自适应，「标准」和「高质量」分别锁定对应的导航 chrome 质量；高质量模式可通过“高质量覆盖全部面板”扩展到 Flutter 内容面板，WebView 覆盖层仍受 role 和 renderer 能力约束。
- 设置格式为 `app_settings_v2`：只接受当前格式；旧设置记录与含旧格式设置的备份都会被拒绝（本应用尚无正式用户，因此不做旧数据迁移）。
- 底部一级导航固定单行窄胶囊，**显示图标和文字**（主体 72dp、图标 20dp、左右外边距 28dp、上下内边距 6dp）；浅色和深色主题分别使用中性玻璃填充 token，选中态使用低透明度主题色胶囊。浏览工具栏固定单行七项（后退、前进、刷新、回首页、标签页、退出、更多），图标 18dp、高度 48dp、宽度等分且**不换行、不折叠、不横向滚动**；只有半透明把手可拖动并持久化位置，工具栏覆盖网页而不改变 WebView 尺寸。「更多」打开底部面板而不是浮层菜单：Android 的 `PopupMenuButton` 浮层会被原生 WebView 盖住，面板可以正确渲染在网页之上。浮在网页上的控件带 `backerColor` 压暗层（深色约 60% 黑、浅色约 65% 白），使主题极性不同的网页背景下文字与图标仍然可读。
- 重启恢复稳定标签 ID、原始与当前地址、标题、档案引用、选择器覆盖和当前标签。选择标签时才创建 WebView；不恢复播放、脚本授权租约或 WebView host ID。
- 默认离开浏览页、被二级页面覆盖或应用转入后台时暂停。可选择当前标签后台播放，由原生静音、HTML 媒体/WebAudio 暂停、媒体会话及前台服务共同控制。系统暂停、继续、停止均绑定当前宿主。缺少必要播放能力的 Android WebView 在离开后销毁宿主并保留标签元数据，以关闭潜在后台音频。进程死亡和重启不会自动播放。
- 入口重定向默认开启且只跟随应用发起的一次入口链；下拉刷新默认关闭。浏览工具栏的 3 秒自动隐藏在标签面板/脚本菜单打开期间暂停。单档案检测、取消、标签容量预留和地址去重保持有效。

## 分层与数据

`AppController` 负责页面协调；用户配置由 `AppSettings` / `SettingsRepository` 管理，标签元数据由 `BrowserSessionStore` 管理，业务备份由 `BackupService` 管理，原生播放由 `BrowserMediaController` / `BrowserMediaService` 管理。探测网络、脚本授权和浏览宿主继续保持不同职责。

数据库升级至 v4。原候选选择器 `main` 迁移为继承档案，原自定义选择器保留显式覆盖。后台检查使用事务领取、续租及每日次数预算；网络请求在事务外运行。脚本源码缓存按内容摘要合并、验证，并使用独立临时目录和原子重命名。

完整备份包含档案、发布页、候选落点、检测历史、脚本、GM 值、固定依赖与资源、脚本错误、偏好及标签元数据。浏览 Cookie、缓存、网页存储、原生运行时、检查租约和档案包批准记录不迁移。

备份 v1 使用两个固定 STORE ZIP 条目。读取前检查原始中央目录、本地头、边界、CRC、摘要和 schema；禁止压缩、加密、descriptor、额外路径及大量目录项。恢复前验证 SQL 类型、日期、脚本元数据、内嵌 JSON、资源摘要和标签约束；恢复事务内再次执行启动模型读取及外键检查。恢复前的业务备份保存在应用私有目录。导入脚本关闭并清除批准摘要，重新确认后才能启用。

## 包名、签名与首次安装

| 用途 | 包名 | 签名 |
| --- | --- | --- |
| 调试与验收 | `dev.vikiea.site_lens.debug` | 本机 debug 签名 |
| 正式 | `dev.vikiea.site_lens` | 仓库外的固定正式签名 |

正式签名配置默认读取 `~/.config/site-lens/signing.properties`，也可用 `SITE_LENS_SIGNING_PROPERTIES` 指定。配置包含 `storeFile/storePassword/keyAlias/keyPassword`，文件与私钥应保存为 0600 并单独备份。缺少配置时 release 构建失败。CI 构建调试 APK，正式包通过本机签名构建。

本轮不兼容旧签名或迁移旧版数据。已安装同包名、不同签名的旧版时，先卸载旧版再安装正式包；卸载会清除该包的数据。首次安装从空库开始，需要自行添加实际发布页或候选地址。旧的独立分享包不再构建，历史导出桥已移除。应用内完整业务备份功能继续供当前版本使用。

## 执行与验收门槛

1. 配置、schema、选择器、检测并发与缓存基础：已实现；修改后验证配置、迁移、选择器和检测行为。
2. 稳定标签、延迟加载、失败恢复和 shutdown 保存：已实现；修改后验证标签恢复和失败恢复。
3. 主题、布局、媒体、完整备份与调试包隔离：已实现；正式发布前验证签名与冻结后的差异。
4. `make check`：Flutter 分析/测试、Pigeon 再生成、脚本与媒体 JS 合约、Android 工具隔离回归。
5. `make acceptance DEVICE=DEVICE_ID`：原生合约、产品流程、导航授权、标签、下拉刷新、HTTP 存活、资源/档案包、六套主题、冷标签、完整备份、真实 VP8/WebM 与 WebAudio、系统媒体按钮。
6. 正式 APK：单独构建、检查 application ID 和证书、安装与界面烟测；与调试验收包分别记录。

验收脚本仅备份、恢复和启动调试包。正常产品 APK 在 integration_test 改写构建输出前单独保留，收尾重新安装该产品 APK并校验数据库字节；保留的目录支持 `make restore-device DEVICE=... BACKUP=...`。媒体操作驱动按包含包名的唯一 MediaSession tag 和同一所有者媒体卡片选择动作。

模拟器证明功能与合约，不能替代物理 Android 设备的性能、后台保活或系统厂商行为验收。当前测试版 Chromium 不包含 H.264 解码器，因此媒体生命周期使用仓库自有 VP8/WebM 及静音 WebAudio 夹具；应用的实际视频格式支持由安装的 WebView 决定。Workmanager 的第三方 Kotlin Gradle Plugin 迁移提示仍需跟随上游处理。
