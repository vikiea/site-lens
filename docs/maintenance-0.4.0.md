## 执行顺序

F/B 已交付的行为先复核，随后 C1 → C2 → D → E。D 的在途文件保持独立，不能混入其他批次提交。高噪声的独立调查可委派只读子代理，主代理负责单写者集成、验收和发布。

## 5554 与资源

使用项目 emulator-check 和带数据库备份/恢复的 acceptance runner。首选 sl_g37、2 核、请求 3072 MiB（允许系统最低 4096 MiB）、host GPU、冷启动。构建与模拟器尽量分阶段运行；只停止本任务已确认空闲的构建 daemon，不终止其他项目或应用。

每 30–60 秒采样 ADB、boot、前台活动、测试进展、进程与宿主内存。达到项目停止条件时保存日志并停止该次设备验证；先查资源根因再继续，不用提高 RAM 掩盖停滞。API 34 以下、API 34+ Vulkan 与非 Vulkan、真实设备的差异分别保留验收边界。
