# 设置导航与长列表回归

## 导航与滚动契约

设置总览只显示短入口。外观、浏览、媒体、数据、设备能力、后台和更新各有独立页面；主题、过滤、脚本、手势和能力分组继续使用子页。设置仍由 AppSettings / SettingsRepository 集中持久化。更新下载由应用控制器持有，离开页面不会取消。

玻璃质量只选择材质，不改变普通面板高度或插入内层滚动。明确需要独立视口的调用方仍可使用 scrollingContent。长数据按页面级惰性列表构建，不能把全部记录放入一个 premium Column。过滤规则源使用 SliverList.builder；编解码器表头、状态、清单和终点共用一个 CustomScrollView。

诊断按需读取，分组和详情订阅最新事实；记录消失时显示未知。查询失败可重试，未知不推断为不支持。枚举 codec 只读取系统描述，不实例化解码器。详情使用与拖动面板共享控制器的单一列表，关闭后保留清单位置。

## 已完成的回归

- 设置入口、主题持久化、更新渠道/Token 条件展示、过滤开关和播放器手势入口。

- 300 项 codec 惰性构建、滑到最后及终点、反向滚动、详情返回位置、失败重试、空结果缓存和 iOS 零枚举。
- 窄屏、大字体、深浅色、非默认主题、0/55/100 不透明度；窄屏不透明度滑块单独占一行。
