# 设置导航与长列表回归

## 导航与滚动契约

设置总览使用外观、浏览、媒体、数据与诊断四个语义折叠面板；有限设置直接在面板内完成。关于和软件更新是两个直接入口，软件更新页自身承载渠道、Token、检查、下载和安装状态。复杂流程继续使用直接二级页面，设置仍由 AppSettings / SettingsRepository 集中持久化。更新下载由应用控制器持有，离开页面不会取消。

玻璃质量只选择材质，不改变普通面板高度或插入内层滚动。明确需要独立视口的调用方仍可使用 scrollingContent。长数据必须按页面级惰性列表构建，不能把全部记录放入一个 premium Column，也不能为了统一外观为每条记录创建玻璃面板。规则源和编解码器清单使用一个受边界约束的玻璃视口与单一 CustomScrollView；如果某个渲染器无法稳定处理共享视口，优先退回页面级列表并保持虚拟化。

诊断按需读取，分组和详情订阅最新事实；记录消失时显示未知。查询失败可重试，未知不推断为不支持。枚举 codec 只读取系统描述，不实例化解码器。规则源按启用状态优先、id 倒序排列；禁用项使用弱化色，刷新和删除进入更多菜单。编解码器与能力详情使用面板内单开折叠，关闭后保留清单位置。
