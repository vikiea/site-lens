# 设置导航与长列表回归

## 导航与滚动契约

设置总览使用外观、浏览、媒体、数据与诊断四个语义分类。分类标题放在玻璃面板外，分类面板始终展开；同一类别的轻量开关和选择项保持可见，避免把普通设置做成折叠玻璃面板。关于和软件更新是两个直接入口，软件更新页自身承载渠道、Token、检查、下载和安装状态。备份与恢复、播放器手势、媒体管理、广告过滤和脚本管理继续使用直接二级页面，设置仍由 AppSettings / SettingsRepository 集中持久化。更新下载由应用控制器持有，离开页面不会取消。

所有二级页面使用统一标题栏。入口行、开关行、诊断行和列表行共用紧凑行 Token；面板内的分割线只区分相邻语义行，设置的标题、选择器和状态保持为一个视觉单元。短内容使用固定高度面板，超过十行的清单才启用面板内部的单一惰性滚动容器；短分组展开很长详情时，只让详情区域在有界高度内滚动，避免面板整体溢出。

外观页保持明暗、不透明度、玻璃质量和主题色在同一个面板内；不透明度在空间足够时与数值和滑块保持一行。浏览页只承载常用开关，媒体页保留后台播放入口和二级媒体/手势页，数据与诊断页提供备份、设备能力和错误日志入口。面向用户的说明只描述使用结果；实现阈值、通道大小和解析器细节留在诊断或错误状态中。

玻璃质量只选择材质，不改变普通面板高度或插入内层滚动。明确需要独立视口的调用方仍可使用 scrollingContent。长数据必须按页面级惰性列表构建，不能把全部记录放入一个 premium Column，也不能为了统一外观为每条记录创建玻璃面板。规则源和编解码器清单使用一个受边界约束的玻璃视口与单一 CustomScrollView；如果某个渲染器无法稳定处理共享视口，优先退回页面级列表并保持虚拟化。

诊断按需读取，分组和详情订阅最新事实；记录消失时显示未知。查询失败可重试，未知不推断为不支持。枚举 codec 只读取系统描述，不实例化解码器。规则源按启用状态优先、id 倒序排列；禁用项使用弱化色，刷新和删除进入更多菜单。编解码器与能力详情使用面板内单开折叠，关闭后保留清单位置。

广告规则源按启用状态优先、id 倒序排列；禁用项统一弱化颜色，规则名保持单行并获得主要宽度，刷新和删除进入紧凑更多菜单。规则源详情在同一面板内单开。错误日志使用一个固定满高面板，只有日志列表滚动，点击日志继续使用底部详情面板。媒体 Tab 与媒体任务使用文件管理器式的面板内文件夹和行列表，长列表保持惰性构建，文件夹和媒体项不再各自创建玻璃面板。

本轮交互约束：主题色是外观面板内的折叠行，默认收起，展开后每行六个候选；开关行保持安静的触摸反馈，只显示开关动画；标题和描述各占一行，视觉文案控制在二十字以内，窄屏通过共享行文字 Token 缩放字号。规则源详情使用统一的标签和值列对齐。

浏览设置提供半透明浮动按钮的点击展开方式：默认打开一行底部浏览导航，也可以选择点击时同时展开全部操作行。WebView 内的脚本菜单和媒体嗅探面板保持轻量，只展示名称与操作；重新嗅探和开始下载使用短暂的一秒状态提示。

媒体库和媒体任务共用文件夹/文件浏览、选择、移动、重命名、复制和删除交互。用户看到的文件夹组织单独持久化，不能修改原生下载缓存路径或任务的可续传身份。根目录只有子文件夹时只展示文件夹，不显示“暂无媒体”类根目录空状态；进入真正为空的文件夹后再显示当前范围的空状态。
