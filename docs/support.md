# 支持清单与安全边界

## 平台

| 能力 | Android | iOS |
|---|---|---|
| 基础浏览 | Android 8.0+ 的系统 WebView | iOS 15+ WKWebView |
| 特权脚本 | 同时检查原生世界与导航生命周期；缺失时关闭 | 每脚本 WKContentWorld + 同世界 WithReply |
| 文档开始/结束/空闲 | 生命周期启动兼容层，由兼容层调度 end/idle；缺少注入能力时关闭 | atDocumentStart 启动兼容层，由兼容层调度 end/idle |
| 检测/发现数据环境 | MULTI_PROFILE 独立 Profile；不支持时拒绝，不共享浏览 Profile | 独立 nonPersistent store，不装用户脚本 |
| 浏览数据 | 默认浏览 Profile，按域名保留 Cookie/网页存储 | default website data store |
| 全屏 | 原生网页视频 custom view；返回优先退出全屏（Google WebView 154 真机通过） | 原生视频；元素全屏仅 iOS 15.4+，待模拟器/真机验证 |

**OS 版本不代表 WebView 增强能力。** Android 编译使用 AndroidX WebKit 1.17.1；运行时决定能力。Chromium 开发 snapshot 的通过不证明 Google Play stable 或所有 OEM 已支持。

## 脚本

- 元数据：`@match`、`@exclude`（HTTP(S) 匹配模式）、`@run-at`、`@grant`、`@connect`、`@require`。允许 `@name:zh-CN`、`@description:en` 等本地化展示字段。限定主框架。URL host 不支持端口声明，URL 本身可带端口。只粘贴元数据头、缺少 `// ==/UserScript==` 或脚本主体时明确标为不可启用。
- 范围模式：`https://example.com/*`、`*://*.example.com/path*`；不支持正则 exclude、`@include`、`<all_urls>` 等扩展语义，导入后禁止启用并显示原因。
- 时机：`document-start`、`document-end`（DOMContentLoaded）、`document-idle`（DOM 就绪后的下一任务）。不宣称资源加载完成。
- 存储：`GM_getValue/GM_setValue/GM_deleteValue/GM_listValues` 与 `GM.getValue/setValue/deleteValue/listValues`。声明对应接口；值仅 JSON，每值 64 KiB、键 256 字符。传统读取是本次文档的独立快照；传统写入无同步成功返回，异步确认和失败日志可见。失败从已提交基线重放待写日志，不恢复未提交值。每次新文档重新预载。
- 样式：`GM_addStyle` / `GM.addStyle`，本 world 直接共享 DOM。
- 菜单：`GM_registerMenuCommand/GM_unregisterMenuCommand` 与 `GM.registerMenuCommand/unregisterMenuCommand`。传统菜单变更异步到达 Flutter；菜单绑定文档与脚本，导航后清空。
- 日志与建元素：`GM_log` / `GM.log` 输出到网页控制台；`GM_addElement` / `GM.addElement` 在共享 DOM 上创建元素（支持 `(tag, attrs)`、`(parent, tag, attrs)` 和对象形式），与 `GM_addStyle` 一样不需要原生桥。
- 信息与系统操作：`GM_info` / `GM.info` 提供脚本元数据；`GM_setClipboard` / `GM.setClipboard` 写入系统剪贴板；Android 支持 `GM_notification` / `GM.notification` 系统通知（首次使用需系统通知权限）；`GM_openInTab` / `GM.openInTab` 通过系统外部浏览器打开 URL；支持同文档 `GM_addValueChangeListener` / `GM_removeValueChangeListener`。
- 网络：`GM_xmlhttpRequest` / `GM.xmlHttpRequest`；异步、文本或 JSON 响应、文本请求体、有限方法/超时/重定向/大小，同一应用最多 8 个 GM 网络并发。传统接口返回 abort handle，现代接口返回带 abort 的 Promise。无同步 XHR、二进制、上传进度或浏览器凭据语义。
- `@connect` 支持域名、`*.域名`、`self`、`*`；需要确认。每跳验证目标，连接时拒绝任一非公共 IP，固定已审核 IP；HTTPS 在固定 IP 上真实 TLS 握手，按原域名校验证书和 SNI。不接受 Cookie、Authorization、Host、Origin、Referer 等敏感/浏览器请求头，不携带浏览器登录 Cookie，不允许 HTTPS 降级。
- 依赖：确认后按声明顺序下载，限制 HTTPS、每项 512 KiB、最多 8 项；跨域依赖重定向默认拒绝。固定 UTF-8 字节与 SHA-256，之后浏览不再下载/自动更新。更换依赖 URL 或重新导入为新脚本才会下载新字节。脚本源码/权限/依赖的确认 digest 同时绑定原生回调 principal，旧版本不能借用新确认。
- `@grant none` 在网页 world 执行，不能使用应用原生存储、网络或菜单。此环境与网页共享 JS；不能给其错误作可靠的特权脚本身份归属。特权脚本的同步执行错误和 GM 持久化错误记入本机脚本日志；任意未捕获异步异常不是完整调试器覆盖范围。
- `unsafeWindow` 只在**没有 GM 特权权限**的脚本中支持：这类脚本运行在网页 world，`unsafeWindow` 就是页面自己的 `window`（真实的页面对象，不是代理），但同时也失去原生存储、网络与菜单权限。`unsafeWindow` 与任何 GM 特权权限同时声明会明确阻止启用——隔离 world 与页面 JS 堆不共享对象，本机不会用假对象冒充页面 window。

`@resource` / `GM_getResourceText` / `GM_getResourceURL` 支持**快照语义**：确认时下载一次、固定字节与 SHA-256，之后浏览不再下载、不自动更新；资源字节变化必须重新确认。`GM_getResourceURL` **只返回 `blob:` URL**（由固定快照生成），绝不返回远端地址，否则脚本可借它绕过 `@connect`。需要动态拉取的资源（例如每次请求都要新内容）不支持，请脚本侧自行解决。

不支持带 GM 特权权限的 `unsafeWindow`、iframe 注入、脚本市场、自动更新、跨文档值变更广播或任意 Tampermonkey 脚本完整兼容。真实脚本需另做兼容检查。

### 浏览页与标签
- 每个标签一个独立原生 WebView 与独立脚本文档代次；切换标签只是重新挂载 PlatformView，页面状态不会重建。
- 页面发起的新窗口（`target="_blank"`、用户手势触发的 `window.open`）不会创建系统弹窗，而是交给应用开新标签；不可达地址与 `about:blank` 会被丢弃，单次最多 8 个标签。
- 浏览工具栏固定单行七项：后退、前进、刷新、回到站点首页、标签页、**退出浏览器到首页（保留会话，可在应用内切回）**、更多；「更多」打开底部面板，里面是新建标签页、脚本菜单、**关闭当前标签页（销毁 WebView）**（面板而非浮层菜单：浮层菜单在原生 WebView 之上会被盖住）。图标 18dp、高度 48dp、宽度等分，**不换行、不折叠、不横向滚动**；工具栏**覆盖**在网页上，不改变 WebView 尺寸。
- 只有半透明把手可拖动（`browserControlsFraction` 持久化，默认底部居中）；**点一下展开工具栏**，工具栏本身固定在底部居中。3 秒自动隐藏的倒计时**只在工具栏/把手自身被点击或触摸时重置**，网页内的点击/滑动/长按不重置（工具栏隐藏时网页里的一次点击只会把它唤出来）；打开标签面板或脚本菜单期间计时暂停。
- 下拉刷新**默认关闭**（下拉手势交还页面和脚本）；在「设置 → 浏览页下拉刷新（Android）」打开后，页面处于顶部时下拉即刷新当前页（该手势只在 Android 浏览宿主上存在，iOS 本来就没有），检测/侦察宿主不启用该手势。「浏览」页在存在会话时提供「切回」与「全部关闭」，「择站」与档案详情页顶部提供一行「切回」。
- 站点弹窗依赖 `window.opener` 与父页面通讯（部分播放器）时不再成立：新标签是独立页面，不会回写原标签。

### 浏览器内的错误提示

- 浏览页顶部的状态提示条来自**浏览 WebView 自身**：证书/TLS 失败、跨文档或历史恢复导致特权脚本撤销（`scriptsSuspended`）、能力不足导致的 fail-closed 等，颜色随状态角色区分。这些状态只在真的创建一个浏览宿主之后才存在，所以检测/侦察页不会提前报告它们；检测侧能报告的部分（HTTP 初筛、首页 DOM、证书错误作为 `ProbeStatus.certificateError`）在候选列表里显示为「证书错误」等状态。
- 提示条可以点 × **清除**：清除只收起横幅，不改变宿主记录的错误状态（测试断言 `errorKind` 仍为 `scriptsSuspended`）。重新导航或刷新后，如果原因还在，提示会再次出现。
- 「关闭全部脚本并重载（恢复）」会真正清空这类状态：重载后的文档没有可撤销的特权脚本，验证结果为 `errorKind == null`。若原因是 TLS/证书本身不可用，重载会立刻再次重现同一提示，这就是"关掉再刷新还是报"的原因，此时用 × 清除或修好网络/证书。

### 导航授权与“无法确认新文档”报错
- 报错文案：`无法确认新文档或历史恢复，特权脚本关闭直至显式刷新`。它表示这次主导航没有匹配到应用刚刚授权的 URL，应用按 fail-closed 撤销当前文档的所有特权脚本，直到用户显式刷新。
- 触发条件：跨文档的历史前进后退、跨 origin 导航，以及无法归入同 origin 在途重定向的未授权 URL 变更。同一文档内、同 origin 的 SPA/hash 导航不会触发；此时文档、JS world 与 token 都未改变，GM 请求仍会逐次校验 origin 与 `@match`。
- **入口跨域 301/302 固定跟随**：镜像站的公共入口域名常常 301 到另一个域名（不同入口域名可能 301 到另一个服务域名）。这条 301 属于**应用自己刚刚发起的那次入口导航**：它由入口服务器选择谁来服务这个页面，和入口页面用 JS `location = ...` 跳转是不同的授权来源。入口跨域跟随固定开启，不作为设置项：只对**应用自己发起的导航**（进入站点、回首页、刷新/下拉刷新）生效，只在**同一条在途导航的重定向事件**上生效，且最多 5 跳、落地即止。
- **页面自己发起的跳转永远不跟随**：点击、页面 JS 的 `location=`、`meta refresh` 都是新的导航，按上面的严格规则处理；自动化回归验证入口文档的 JS 跳转到跨 origin 后仍然撤销，落点文档拿不到特权脚本。
- 已修复的误报：WebView 会把 `loadUrl` 的目标规范化（`https://host` → `https://host/`），早期版本按原始字符串比较，导致所有「无结尾斜杠」入口一进入就被判成未授权。现在按规范化 URL（scheme/host/默认端口/path/query，忽略 fragment）比较，`integration_test/navigation_lease_test.dart` 固定该行为。
- 如何避免：优先用带完整路径的入口地址；遇到该提示时点浮层里的刷新按钮重新授权并重载；hash 路由站点建议直接进入目标路径而不是依赖同文档跳转。
- 服务器 3xx 重定向不会触发该提示：同 origin 重定向被视为同一在途导航；跨 origin 重定向仍会撤销。`integration_test/navigation_lease_test.dart` 同时覆盖无结尾斜杠、同 origin 重定向和 SPA 同文档切换。

### `@match` 的范围

- `*://*/*` 表示所有 http/https 地址（其他域名形式如 `*://*.example.com/path*` 同理），镜像站也在内；没有路径的地址（例如 `https://host`，没有结尾 `/`）按浏览器语义当作 `/` 处理，同样匹配。声明 `@match` 后仍需在「脚本」页确认并启用，且全局「关闭全部脚本」开关必须是关的。
- 三处匹配实现（Dart 侧判定、Android 原生 GM 请求校验、网页内运行时）使用同一套正则与同一套规范化，任何一处不一致都会让脚本或它的 GM 能力被静默拒绝；修改匹配规则时必须同时改三处并跑 `tool/test_runtime.mjs`。
- 规则里写的 scheme/host 按小写比较（`https://example.com/*` 不匹配 `HTTPS://EXAMPLE.COM/`）。Dart 侧解析会把 scheme/host 小写化，网页内运行时用的是浏览器给的 `location.href`（规范化后恒为小写），所以实际遇不到——这是一条**预先存在**的差异，记在这里以免以后误判。

### 多标签与地址输入

- 一个档案可以有多个标签页。打开另一个镜像落点、或再次从档案进入，都是**追加**一个标签（同 URL 则复用该标签），不会销毁当前标签；标签只在用户显式关闭时销毁，上限 8 个，超出时明确报错。
- 新建标签页/添加发布页/手动候选这些**用户输入**的地址可以省略 `http(s)://` 前缀（按 `https://` 处理）；显式写的 `http://` 保持原样。应用内部生成的 URL 仍按严格规则解析，不适用这条宽松规则。

### 兼容预检

- 首版只运行声明范围内的 GM 子集。未实现的权限（包括需要特权权限的 `unsafeWindow`）会明确阻止启用，不会静默忽略。
- 脚本源码上限为 16 MiB。源码写入应用私有文件，Pigeon 只传包装体和受控路径；原生读取时再次校验路径必须位于应用文件目录。
- 导入前可用 `dart run tool/verify_script.dart <file.user.js>` 跑同一套解析器，先看 `canEnable` 与不支持的权限，再决定是否导入。
- `// ==UserScript==` 与 `// ==/UserScript==` 必须成对出现并包含脚本主体。只粘贴元数据头时保留源码但禁止启用，并给出截断位置提示。

## 生命周期与网络范围

- 原生每脚本 listener/world、批准 revision 与随机 document token 决定身份，忽略 JS 自报 scriptId/revision。核验实际主框架与来源，并在异步结果发送前再次检查。
- 新导航先撤销旧文档，重新取授权源码/快照；快速导航的迟到准备结果不能加载页面。取消、销毁、跨文档历史恢复或无法确认的导航使旧桥失效；同 origin 的同文档 SPA/hash 切换保留当前文档租约。历史恢复的特权脚本保守关闭，须显式刷新。
- 隔离 world **共享 DOM**，不是页面内容保密机制，也不能阻止已获授权脚本从 DOM 读取数据。固定依赖与脚本同属一个授权 principal。
- 取消不能回滚已经提交的存储写入或已经发出的网络请求；它阻止后续操作/旧回复被当成当前结果。
- 自动 HTTP 检测使用公共目标策略；发现/验证原生主导航有公共 DNS 预检。**普通 WebView 渲染层不是完整网络 sandbox；该预检不等于 WebView 的连接时 DNS/IP pin，也不覆盖所有子资源。**不为任意网页请求宣称同等 GM 网络约束。
- 系统 Fake-IP DNS（例如解析为 198.18.0.0/15）和代理导致的私网解析会被安全策略拒绝，不为让测试通过放宽私网禁令；这类失败按“网络环境/Fake-IP”提示，不归因站点证书错误。普通手动浏览仍走系统 WebView/代理；自动检测与 GM 网络要求公共直连 DNS。
- TLS/验证码/交互失败均保留理由。DOM 就绪规则是显式、可调整的有限判据，不代表页面内容可信、完整服务功能或视频质量。

## 未完成的验收

当前真实发布页和 iOS 模拟器/真机仍须验收，实际证据见 `implementation.md`。**源码存在、静态审查和语法解析不能替代运行验收。**

### 站点档案、迁移与"首页已就绪"的等价性假设

- **档案是一等对象**。每个站点档案维护自己的发布页、候选落点、脚本与存活状态；导入/导出以档案包为单位。schema `v1 → v2 → v3` 迁移在**单个事务内**完成：一次失败会回滚到迁移前，`sources` 变为 `profiles` + `profile_pages`，手动候选归入「未归类」，脚本**不自动绑定**任何档案（广泛的 `*://*/*` 兜底会让自动归属不可靠）。迁移使用合成公开 fixture 做回归（逐表行数 + 字段级比对 + 脚本仍可注册 + 注入失败回滚 + `user_version` 落后重试）。
- **"首页已就绪" ≠ 可播放。** 本产品对排序的唯一依据是：进入候选落点、核心 DOM 选择器已可见且有内容（默认 `main`）。这是基于"这批镜像站模板同构，DOM 就绪 ≈ 可播"的**显式等价性假设，不是事实**。不同站点、反爬或播放器初始化慢时，首页已就绪仍可能无法播放；应用不会自动跳站、不接管播放器、不承诺画质。
- **检测在独立 Profile 中运行**：不与浏览会话共享 Cookie/存储；非浏览用途的宿主必须拿到 `privateProbes` 能力，否则直接拒绝。
- **进站前检测**：默认先跑该档案一轮（发布页侦察 → HTTP 初筛 → 核心 DOM 验证）再进；有上次落点时走快路径，6 秒内未就绪或遇到网络/证书错误时自动回落到本轮更优落点，**失败的标签保留可见**，不静默替换页面。
- **归档包不含运行时状态**：不写 GM 存储值、检测历史、错误日志与任何"我已确认"标记；导入的脚本一律 `enabled=0` + 未确认，需在本机确认权限与依赖后才能启用。
- **后台存活检查是尽力而为**：仅充电 + WiFi、每天最多两次、只做 HTTP 初筛（不启动 WebView）。Android Doze 与厂商省电下不保证时效；它只更新状态徽章，**不产生推荐、不写排名**。


## Android 现代化首版

当前界面使用站点、浏览、设置三个入口（底部导航为带文字标签的窄胶囊，浅色纯白底、深色纯黑底），脚本管理是设置二级页面。界面固定为 iOS 27 液态玻璃，玻璃质量提供「自动 / 标准 / 高质量」三档；选择明暗模式、主题色、玻璃质量、播放策略及数据备份的行为与包名/签名边界见 [android-modernization.md](android-modernization.md)。当前 schema 为 v4；候选选择器支持继承与显式覆盖。真实 WebView 的媒体策略由原生控制，缺少必要能力时后台播放不可用，并在离开后销毁宿主、保留标签元数据。完整备份不迁移 Cookie 或网页存储，恢复脚本需要重新确认。前面的旧阶段记录不代表本轮 iOS 或真机验收。
