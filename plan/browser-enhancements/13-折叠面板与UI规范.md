# 折叠面板与 UI 规范

## 问题和目标

带折叠功能的面板在点击或展开时出现阴影变化，和全局液态玻璃规范冲突。需要统一所有 `ExpansionTile`、可折叠面板和相关 Material 状态的无阴影表现，并同步 UI Skill。

## 实现设计

- 在共享 UI 原语或主题层提供统一的折叠面板组件/主题：展开、收起、按下、聚焦和悬停状态均不增加 elevation 或 shadow。
- 保留 Material 的语义、焦点、键盘和展开动画；只调整 surface、shape、overlayColor 和 elevation。
- 逐项替换设置、档案、检测、高级区域等页面的裸 `ExpansionTile`，避免页面局部覆盖规范。
- 更新 `.agents/skills/site-lens-ui/SKILL.md` 及其 `references/ui-system.md`，明确折叠面板交互不能引入阴影，并补 light/dark/非默认主题验收清单。

## 验收

- 点击前后截图/Widget 检查中没有额外阴影或黑边。
- 折叠面板在浅色、深色和非默认主题保持相同层次关系。
- 长中文、键盘焦点、无障碍展开状态和点击反馈仍可用。
- 共享原语覆盖所有页面，不允许新页面重新使用裸 `ExpansionTile`。

## 独立审查门禁

审查所有 `ExpansionTile` 使用点、主题覆盖优先级和嵌套玻璃边界；提交前运行 UI 目标测试和 L1 检查，并记录 UI Skill 文档变更。

## 实现状态

已在 `5f01d79`、`db70020` 完成。所有现有 `ExpansionTile` 均通过 `SiteLensFoldable`，展开、收起和按下状态使用透明 surface、零 elevation；UI Skill 及参考规范已同步更新，完整 UI 回归通过。
