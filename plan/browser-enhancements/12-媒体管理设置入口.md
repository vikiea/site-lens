# 媒体管理设置入口

## 问题和目标

“下载完成自动转 MP4”目前直接放在总设置列表，和媒体任务管理分散。需要增加“媒体管理”子菜单，把媒体相关偏好和任务入口集中起来，并保持旧设置键兼容。

## 实现设计

- 设置页增加“媒体管理”入口，子页承载媒体任务、自动 MP4、下载行为和缓存相关设置。
- `autoConvertToMp4` 的持久化键保持不变，迁移只改变 UI 入口，不丢失已有值。
- 子页说明自动 MP4 的适用范围、失败回退和磁盘影响；不暴露实现组件名。
- 与媒体任务页共享统一的页面壳、面板、状态提示和无阴影折叠规范。

## 验收

- 旧用户进入“媒体管理”仍能看到原来的开关值。
- 开关修改后自动转码回调立即生效，重启后保持。
- 总设置不再出现重复的自动 MP4 开关。
- 无媒体能力的平台显示可读的不支持状态。

## 独立审查门禁

审查设置键兼容、导航返回、深链和无 Android 原生能力路径；提交前通过设置页、设置持久化和媒体任务测试。
