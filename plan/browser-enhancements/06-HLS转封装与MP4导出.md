# 06 HLS 转封装与 MP4 导出

## 基线、目标与依赖

基线为 `origin/main@ca904c36ff6bede07ab8092dde16e9903a41a7c8`，应用版本 `0.1.9+7`。依赖 `05` 提供完整、已授权的本地 HLS 清单、初始化段、分片和缓存引用。

目标是把已缓存 HLS 复制封装成可交付 MP4，不做实时转码。非目标是通用 FFmpeg 命令执行、导出阶段远程联网、直播录制和把半成品当作已交付文件。

## 工具和输入边界

- 使用固定版本 FFmpeg 最小能力库；JNI 只暴露开始、进度、取消和错误。
- 导出前确认清单、初始化段、分片、字节范围和必要密钥都在当前任务缓存中，且摘要/路径一致。
- 生成只引用本地输入的中间清单；FFmpeg 不能访问远程网络。
- 复制音视频流；容器/编码不兼容时明确失败。通过 Android SAF 交付。

## 状态机和执行步骤

```text
排队 -> 准备本地输入 -> 转封装 -> 输出校验 -> SAF 交付 -> 成功
                         \-> 取消/失败（清理半成品，保留缓存）
```

1. 固定 FFmpeg 源码、许可证、构建参数和 ABI 范围。
2. 从 `MediaTask` 解析本地输入，拒绝缺段、缺密钥、路径越界和远程 URI。
3. 生成临时清单并调用受限 JNI；只允许一个导出任务并支持取消。
4. 分阶段检查磁盘空间，输出写临时文件，完成后校验容器、时长和流。
5. SAF 交付成功才标记已交付；交付失败保留已校验输出供重新交付。
6. 将可播放 MP4 引用交给 `07`，并向 `08` 输出证据字段。

## 失败、回滚和验收（本轮不执行）

- 取消/失败清理半成品，不删除下载缓存。
- 磁盘不足、清单损坏、缺密钥、时间戳异常、编码/容器不兼容都返回独立错误码。
- 覆盖 TS、fMP4、独立音视频、AES-128、字节范围、取消、输出目录失效和交付失败。
- 真实播放检查画面、声音、时长、拖动和音视频同步；没有真实设备只能保留待验收。

输出：受限 FFmpeg/JNI 契约、本地输入校验、导出状态机和 MP4 资源引用。禁止在本阶段实现投屏协议或任意网络中继。
