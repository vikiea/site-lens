# 01 基础契约与数据迁移

## 基线、目标与边界

基线为 `origin/main` 提交 `ca904c36ff6bede07ab8092dde16e9903a41a7c8`，应用版本 `0.1.9+7`。当前 `AppDatabase` 为 schema v4，`ProfilePack` 为 format v2，设置键为 `app_settings_v2`，浏览会话键为 `browserSession_v1`。

目标是为过滤和媒体能力建立稳定的跨层身份、DTO、迁移和备份契约。非目标是本阶段实现过滤、播放器、下载、FFmpeg 或 DLNA。

前置依赖：`00-总控计划.md` 已确认基线和依赖 DAG。输出供 `02` 至 `07` 使用。

## 模块、接口和权威存储

- 现有模块：`lib/data/database.dart`、`lib/data/profile_pack.dart`、`lib/settings/app_settings.dart`、`lib/browser/browser_session.dart`、`lib/browser/browser_session_store.dart`、`lib/web_host/native_hosts.dart`、`pigeons/web_host.dart`。
- 统一跨层身份：`hostId + generation + sourceUrl + candidateId/taskId`；需要时增加一次性 capability token。
- 规划 Pigeon DTO：`FilterSnapshot`、`FilterPolicy`、`MediaCandidate`、`MediaTask`、`CastDevice`、`CastSession`、`HostFilterContext`。DTO 只含可审计元数据、状态和错误码，不含 Cookie、Authorization、Web Storage 或原生路径。
- Drift 保存来源、版本、摘要、状态、Profile 归属、任务元数据和错误码；规则正文、缓存分片和临时输出保存于应用私有目录；原生任务仓库是下载和导出状态的唯一写权威。
- 业务备份保留 Profile、候选、检测历史、脚本元数据、过滤配置和标签元数据；排除 Cookie、Web Storage、批准运行时租约、媒体缓存、媒体凭据、下载分片和投屏会话。

## 数据流和状态机

```text
用户配置/导入 -> AppController -> Repository -> Drift/私有文件
宿主事件 -> NativeHosts/Pigeon -> generation 校验 -> Flutter 快照
媒体候选 -> 授权校验 -> 原生任务仓库 -> MediaTask 事件
```

迁移状态为 `读取旧 schema -> 事务升级 -> 约束校验 -> 提交`；任一步失败都保留旧数据库并返回可解释错误。媒体任务状态由原生仓库管理，Flutter 断线重连后重新读取快照而不是重放本地猜测。

## 执行步骤

1. 盘点 v4 表、设置键、档案包字段、生成的 Pigeon 文件和现有错误处理。
2. 设计 v5 过滤源/策略/快照元数据表，字段只保存摘要、状态、来源和文件引用。
3. 设计 v3 ProfilePack：可携带 Profile 过滤配置和域名例外，兼容读取 v2，拒绝未知高版本。
4. 为候选、任务、授权和错误码建立不可变 DTO 与序列化规则；生成绑定后检查 Dart/Kotlin/Swift 一致性。
5. 为备份恢复定义排除项和重新授权流程：脚本关闭、媒体缓存不恢复、标签只恢复元数据。
6. 添加事务失败、旧数据不完整、文件摘要不匹配和恢复中断的回滚说明。
7. 输出迁移顺序、字段兼容表和供后续计划引用的契约版本。

## 失败处理与回滚

- v4 打开失败时不尝试修复原文件；保留原文件并报告迁移错误。
- 规则文件缺失或摘要不符时将快照标记为不可用，继续使用上一有效快照。
- v2 档案包只读导入；任何字段无法解释则拒绝导入，不部分写入。
- Pigeon 生成不一致时停止后续阶段，不手工编辑生成文件绕过检查。

## 计划测试与验收（本轮不执行）

- v4→v5 真实数据库、事务回滚、外键和重启读取。
- v2 导入、v3 导出/导入、高版本拒绝和备份排除项。
- generation 变化、标签销毁、进程重启后的迟到事件拒绝。
- Pigeon 绑定无意外差异，所有 DTO 不含敏感字段。

通过条件是旧数据可读、迁移可回滚、备份边界可证明、DTO 身份和错误码被 `02`-`07` 复用。

## 输出与禁止事项

输出：schema v5+ 迁移设计、ProfilePack v3 兼容表、DTO/错误码表、备份白名单/黑名单和回滚 runbook。禁止在本阶段实现任何过滤、播放、下载、导出或投屏功能。
