# 28 播放器播放列表与集数切换

## 目标

播放器打开任务时自动带入同系列目录中的可播放媒体，并支持上一集/下一集快速切换。

## 实现边界

- 以 `MediaTask.seriesDirectoryName` 作为系列边界，只收集已完成或可播放任务。
- 优先按集数排序，缺少集数时使用标题和更新时间稳定排序。
- 播放器底部提供上一集/下一集图标按钮，首尾任务自动禁用。
- 切换复用本地缓存优先、远程候选其次的播放入口，切换失败保留当前会话并显示可读提示。
- 播放列表仅属于当前播放器会话，不改变任务状态和下载队列。

## 验收

- 单元测试覆盖同目录过滤、集数排序、首尾禁用和切换目标选择。
- Widget 测试覆盖上一集/下一集按钮状态。
- 独立代码审查后执行完整 `tool/check.sh`，再进行真实设备连续播放验收。
