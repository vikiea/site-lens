# 播放器停止与全屏交互

## 目标

明确停止按钮与返回按钮的区别，避免停止后仍停留在空播放器；播放控制、状态栏和全屏模式的显示状态保持一致。

## 实现边界

- 停止操作结束当前媒体会话并立即退出播放器；返回操作只负责离开路由，退出时同样安全关闭会话。
- 播放器控制层随操作按钮一起显示/隐藏，点击画面切换；状态栏不独立悬浮在隐藏控制层之外。
- “更多”菜单提供全屏开关；全屏隐藏系统状态栏和导航栏，退出时恢复原系统 UI 和方向偏好。
- 横竖屏切换保留为播放器显示设置，不能影响会话生命周期。

## 验收

- 停止按钮和返回按钮行为可理解且不会留下播放栏或后台会话。
- 控件隐藏时状态栏、进度条和操作按钮一起隐藏，点击画面可恢复。
- 全屏进入/退出、返回手势和异常退出均恢复系统 UI。
